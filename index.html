Game privacy

NIGHTFALL SUBZERO is a single-player game designed for offline play. The reviewed game code does not implement player accounts, online multiplayer, chat, cloud saves, advertising, in-app purchases, analytics uploads or a remote AI service. We do not operate a gameplay data collection service for this Unity edition. Unity cloud diagnostics, analytics, ads and purchasing are disabled in the reviewed project settings.

The game stores the following information locally to preserve your progress and preferences:

  • Campaign checkpoints: mission stage, kills, objectives and equipment state, supplies, collected caches, puzzle state, grenades, demolition state and related mission progress.
  • Preferences: graphics profile, footsteps, mouse sensitivity, master volume, weapon/camera movement preference and the last campaign operation.
  • Field intelligence collection: collection flags for 18 operations, with two discoveries per operation, plus a checksum used to detect corrupted data.

These game records do not request your real name, email address, payment details or conversations. Standalone mission replay does not overwrite campaign checkpoints; collected field intelligence and changed settings can still be saved locally.

Storage, logs and platform services

For the unpackaged Windows Unity game, the expected save location is %USERPROFILE%\AppData\LocalLow\NIGHTFALL SUBZERO\NIGHTFALL SUBZERO. Checkpoints use winter-lance-unity.json or campaign-<operation-id>-unity.json, with .previous backups and possible .tmp staging files. The collection archive is field-intelligence-v1.dat, with a .bak backup and possible temporary files. Preferences use Unity PlayerPrefs; on Windows these normally reside in the current user's registry under the game's company/product names. Store packaging may change or redirect storage locations.

Unity and Windows can generate local diagnostic logs and crash information. Explicit development/QA runs can also write hardware/performance information, reports and screenshots to selected diagnostic folders. This source review does not establish every engine or operating-system crash-handler behavior, installed-package location, or automatic retention period. There is no automatic expiry implemented for the reviewed game save records.

Microsoft Store downloads, licensing, purchases and platform diagnostics are handled separately by Microsoft and Windows. A Store package's internet capability alone does not establish that the game transmits data. The reviewed source does not prove that every engine or platform component is network-silent.

Local data controls

You control the local records on your Windows account. Close the game and back up your saves before removing checkpoint or collection files; removing them loses the corresponding progress. Preferences are separate PlayerPrefs records. There is no in-game account-deletion service or verified one-click deletion of all files and preferences. Uninstalling or updating a Store package is not a verified way to erase or preserve every local record.

We cannot remotely retrieve or delete saves stored only on your computer. For help locating data in a specific installation, use the support route below without uploading private files.

Support

Submit a non-sensitive bug report or support request through the public GitHub Issues page. You need a GitHub account to submit an issue; browsing this information page does not require a game account.

GitHub issues are public. Do not post personal data, email addresses, payment information, passwords, keys, private files, full local paths or unredacted logs/screenshots. There is no private support inbox or private upload form provided by this site.

Include the Unity game version, whether you use a Store package or unpackaged build, the operation name, steps to reproduce, what you expected, and what happened. General Windows version and GPU model can help. Redact anything identifying you before voluntarily sharing a small relevant diagnostic excerpt.
